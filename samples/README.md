# 样片

GitHub 网页点 `.mp4` 往往只会在线播放、下不下来。请用下面任一方式：

1. 工作台右侧「下载这支成片」（把文件存到本机）
2. 下载 zip（GitHub 可直接保存）：
   - [粤语车广告 30s.zip](https://github.com/wulongjun650-prog/1111/raw/cursor/video-generation-studio-b3d5/samples/car-ad-30s.zip)
   - [国风短片 30s.zip](https://github.com/wulongjun650-prog/1111/raw/cursor/video-generation-studio-b3d5/samples/demo-30s.zip)
3. 本地：`./start.sh` 后打开 http://127.0.0.1:8000

文件：

- `car-ad-30s.mp4` / `car-ad-30s.zip`：粤语豪华车清货广告，精确 30.00 秒
- `demo-30s.mp4` / `demo-30s.zip`：国风短片，约 30 秒
