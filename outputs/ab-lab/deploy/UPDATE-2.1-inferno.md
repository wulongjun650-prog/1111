# v2.1 Inferno 开发预览包

本包完成中文国家/语言搜索多选、国家归属显示、UA 设备详情及黑红紫主题。不是已经在你的宝塔服务器验收的正式版；多域名自动建站、反代、证书功能仍未完成，详情见 UPDATE-2-preview.md。

## 验收和升级

1. 先解压到新目录，使用独立数据目录运行本地验收。不要把免登录本地模式发布到公网。
2. 已安装服务器升级前，停止本程序的 admin、target 服务（若启用 dns 也停止），完整备份 `/opt/ab-lab`、`/etc/ab-lab`、`/var/lib/ab-lab`。其他站点不需要停止。
3. 本包建议先在测试服务器验收。替换代码时需同步更新 `ablab/`、`static/`、`templates/`、`run.py`、`requirements.txt`，并复制完整 `resources/`（包含国家库和授权说明）到 `/opt/ab-lab/resources/`。保留配置、账号、业务数据库、上传内容与原有服务文件；不要覆盖 `/etc/ab-lab/config.json` 或数据目录。应用用户必须能读取代码和国家库。
4. 使用现有虚拟环境安装 requirements.txt 后，按现有正式配置启动本程序服务。已安装实例不要重跑仅供首次安装的 install.sh。
5. 后台“国家识别”应显示就绪和库日期。刷新浏览器后检查新主题、输入“韩国”“韩语”的建议并保存，重新选择同一域名验证设置。用自己的公网设备访问后检查新增日志。若代理前还有 CDN，需要另行正确配置可信真实 IP 链路；本轮未自动修改代理配置。

首次打开各站点数据时自动为 events 表增加可空的 device_details 列，可重复执行。旧日志保留原样；只有新访问采集新字段，不会从掩码 IP 或已丢失的 UA 推造历史信息。回滚前再次停止服务并保存当前完整数据快照，再恢复相匹配的代码与备份；不要直接删除 sites/、registry.db 或旧包。

## 国家与设备的边界

- 默认离线使用 DB-IP Country Lite 2026-09，8,340,464 字节；授权 CC BY 4.0，保留页面底部署名及 resources/README.md。无需发送访客 IP 到外部 API。
- 已指定 geoip_path / AB_GEOIP_PATH 的实例仍使用指定文件；若文件失效，会告警且显示未知，不静默切换数据源。不要填写无效路径来启用内置库。
- 内网、回环地址、国家库未覆盖地址及旧记录仍可能未知，IP 国家归属并非实际位置，不保证全量或百分之百准确。库需定期从官方来源人工更新。
- 设备、系统及浏览器来自 UA 声明，可被伪造或精简。包含型号时显示型号；iPhone 没有具体型号时只显示 iPhone，不猜测代数。Windows 10/11 共用 UA 时显示“Windows 10 / 11”。
