# v2 开发预览验证记录

本轮实现范围：域名登记、每站独立 Store 与明确站点 API、Host 路由、独立签名预览、UI切换、DNS只读检查和单项面板能力检查。完整自动宝塔接入未完成。

## 自动测试

- 原版基线：75 Python 测试通过。
- 新增测试先以模块/函数缺失失败，再实现对应模块；本地测试链接回归先以错误的原站响应失败，再修复斜杠。
- 当前源码：105 Python 测试、6 Node 测试通过；JS语法检查通过。
- 覆盖：非法/重复/管理域名拒绝，原站数据保留与幂等登记，SQLite一致性备份，配置/版本/计数隔离，跨站发布/预览拒绝，未知 Host 拒绝，公网路径不能切换其他站点，暂停代次保护，超过256KiB的站点上传，目录重定向保留站点前缀。
- 网络测试使用 httpx MockTransport：A混合记录、AAAA冲突、超时、错误脱敏、v2数值0成功与布尔false失败、只读调用约束、状态持久化和重试。不等同于真实宝塔联调或证书测试。
- 测试框架仍有两个现有弃用警告，不影响用例结果。
