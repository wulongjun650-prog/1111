# 宝塔 / aaPanel 安装与验收

目标：Ubuntu + Nginx + systemd，Python 3.12 或更高版本。无 Docker、无 MySQL。一个管理员、两个 HTTPS 域名。

本包已在 Windows 上测试业务、权限边界及配置生成；**没有在真实 Ubuntu/宝塔上执行安装，不表示已经发布成功**。下面是首次安装流程；不要对现有站点直接覆盖操作。

## 1. 准备

- 访客域名，例如 `lab.example.com`；后台域名，例如 `admin.lab.example.com`。这只是示例，安装时输入你实际拥有的域名。
- 两个域名解析到服务器。在宝塔创建两个**新的纯静态站点**，不要复用已有业务站点，不安装 PHP、不创建数据库。
- 为两个站点分别申请有效 SSL 证书，并启用强制 HTTPS。保持宝塔自己的证书续期验证配置。
- 只开放需要的 80/443。8765/8766 只监听 127.0.0.1，不需要且不应开放。后台不依赖宝塔面板的登录会话。
- 检查服务器可用内存和磁盘。你的机器有其他站点，不能仅按总内存判断剩余容量；本系统单次密码校验约需128MiB，加上 Python、Nginx 和已有站点的占用。
- 首次接入请使用 DNS 直连，不套 CDN/其他反向代理。否则 `$remote_addr` 会变成 CDN 地址，国家/IP/次数判断均会不准确。这里不自动信任客户端的 X-Forwarded-For。

在服务器终端检查（不要使用宝塔面板自身的内部 Python 环境）：

```bash
python3 --version
```

如果没有 Python/venv，可通过 Ubuntu 软件包管理器安装：

```bash
sudo apt-get update
sudo apt-get install python3 python3-venv
```

需要 `python3` 为3.12或更高、systemd 正常运行、Nginx 已由宝塔安装。此脚本不自动更改系统 Python 版本或已安装的站点组件。

## 2. 安装程序

把压缩包上传并解压到**网站根目录以外**的私人暂存目录，例如 `/root/ab-lab-release`。不要把源码、数据库或压缩包放进访客网站目录。

进入包含 `run.py` 的目录，执行：

```bash
sudo bash deploy/install.sh
```

脚本会联网安装 requirements.txt 中的固定依赖，提示输入两个域名、管理员账号和密码。密码不回显、不作为命令参数、不写进配置文件，仅保存带随机盐的 scrypt 散列。密码至少12字符。

只创建以下项目自己的目录和服务：

| 项目 | 位置 |
| --- | --- |
| 程序和虚拟环境（root 拥有） | `/opt/ab-lab` |
| 域名等非密码配置（root:ab-lab，0640） | `/etc/ab-lab/config.json` |
| 数据库、页面内容（ab-lab 用户，私有目录） | `/var/lib/ab-lab` |
| 后台服务 | `ab-lab-admin.service` → 127.0.0.1:8765 |
| 访客服务 | `ab-lab-target.service` → 127.0.0.1:8766 |

两个服务使用非 root 的 `ab-lab` 用户。安装脚本遇到已有同名目录、用户或 service 文件会停止，不覆盖。中途中断也会保留已生成文件，避免清理误删；先检查报错及现有文件，不要反复运行或直接删除目录。

脚本**不修改 Nginx、不替你申请证书、不修改防火墙，也不操作其他站点**。此时只有本机服务启动，公网尚未接入。

## 3. 接入两个宝塔站点

在宝塔对应**新站点**的 Nginx 配置中操作，先备份该站点配置：

1. 后台站点使用 `/etc/ab-lab/nginx-admin.conf` 的内容。
2. 访客站点使用 `/etc/ab-lab/nginx-target.conf` 的内容。
3. 将片段放到各自 HTTPS `server { ... }` **内部**，不要放在整个配置文件外部，也不要嵌进已有 `location`。
4. 替换该新站点原来的 `location /` 或旧反向代理配置，避免重复。片段的 `location ^~ /` 将应用路径整体转交服务，避免图片/JS被旧静态缓存规则截获。若原来已有 `client_max_body_size`，只保留一个。
5. 保留宝塔生成的 `listen`、`server_name`、证书路径和证书续期配置；不要复制另一个站点的 SSL 私钥。保持 HTTP 到 HTTPS 跳转。
6. ACME 验证需要独立的 `location ^~ /.well-known/acme-challenge/` 或宝塔已有的更长前缀 location；仅有正则匹配的验证 location 可能被本包的 `^~ /` 排除。请确认原有 ACME 验证仍可访问，再测试续期。不要给 ACME 路径设置登录。
7. 使用宝塔的配置检查；检查通过后重载 Nginx。**配置未通过时不要强行重启。**

片段把 Host 固定为对应域名，覆盖 `X-Real-IP`、`X-Forwarded-Proto`，清空其他转发头，关闭代理缓存。不要改成客户端可自行传入的头；不要打开 Uvicorn 的代理头信任。若需要 CDN，须另外审核可信 CDN IP 段和真实 IP 链路后再接入。

不要用旧的本地 `python run.py` 命令替代 systemd 中的 `--config` 生产启动方式。生产请求要求 HTTPS代理头、匹配域名及本机代理来源，直接访问上游返回403是预期边界。

## 4. 首次使用与上线验收

在浏览器地址栏直接打开后台 HTTPS 域名，账号密码登录。没有验证码、注册或订阅。然后：

1. 上传包内 `demo/A.zip`、`demo/B.zip`，各自发布。
2. 打开访客域名。在「A/B 内容」页上方依次选「放行后展示 A」「放行后展示 B」，刷新**同一个访客地址**，确认放行访问变化和 CSS/JS/图片加载，拦截访问仍然展示 A。
3. 保持规则防护开启，测试手机/电脑、IP黑白名单、次数限制与重置。防护关闭时所有访客跟随放行后选择；概览的「全部访问 A/B」则跳过规则。用日志核对原因。
4. 登录后退出，再直接访问后台 `/api/state` 应是401；未登录访问后台首页应跳登录页。访客 `/api/state` 应是404。
5. 上传新版本、预览但不发布，确认不改变在线版本；发布旧版本验证回滚。
6. 重启两个服务后确认页面、规则、账号仍保留；旧会话可继续至原8小时有效期，改密码会立即撤销旧会话。
7. 验证 HTTP 自动跳 HTTPS、证书续期、8765/8766 不对外监听，以及原有站点仍正常。

未经上述服务器验收，不应宣称公网发布完成。页面中“国家未加载”不是故障：国家数据库需要你自行合法提供。

## 5. 常用维护

```bash
sudo systemctl status ab-lab-admin ab-lab-target --no-pager
sudo journalctl -u ab-lab-admin -u ab-lab-target -n 80 --no-pager
sudo systemctl restart ab-lab-admin ab-lab-target
```

重设账号密码（使用服务用户，避免把数据库变成 root 所有）：

```bash
sudo -u ab-lab /opt/ab-lab/.venv/bin/python /opt/ab-lab/deploy/configure.py --set-password
```

登录每个IP最多5次尝试/15分钟，全局最多30次/分钟，成功登录清除该IP记录；无需验证码。遇到限速等待窗口到期，或在服务器终端重设密码（同时清除登录尝试）。

国家识别：合法取得 MaxMind Country/City `.mmdb` 后放到 `/var/lib/ab-lab/GeoIP.mmdb`，保证 ab-lab 用户可读。在 `/etc/ab-lab/config.json` 中把 `geoip_path` 设为该绝对路径，重启两个服务。不要开放数据库下载地址。未加载数据库时，开启国家允许名单会把未知地区访问分到 A；模拟器不是实际 IP 定位结果。

备份：停止两个服务，再把 `/var/lib/ab-lab`、`/etc/ab-lab`、对应程序版本和这两个宝塔站点配置备份到站点根目录以外；完成后启动服务。数据库内包含密钥、密码散列和会话，不要上传公开空间。恢复时停止服务、保留原备份，恢复数据为 ab-lab 所有、目录权限0700，再启动并验收。

升级：首次安装脚本不是升级脚本。先备份和停服务，再审查新版本说明，更新程序和依赖；**不要覆盖数据或直接删除旧目录**。本次放行后切换功能的升级见 [UPDATE-1.1.md](UPDATE-1.1.md)。本版本暂不提供自动在线更新/卸载，避免影响已有25个站点。

## 6. 已知边界

- UA、设备、语言、IP 地理位置是可出错的访问特征，不是可靠身份认证；不承诺识别全部 Google 爬虫，也不承诺绕过任何第三方审核。
- 数据上传解压有限额，但长期不断上传版本会占磁盘，定期检查空间。本版本不自动删除历史版本。
- 静态页被沙箱隔离；依赖同源存储、Service Worker、模块跨域加载的页面可能不兼容。详见 README。
- 对你自己的靶机/授权环境提供可解释规则，不复制参考站的未公开识别算法，也不含它的收费、订阅功能。
