# AB Lab · 多域名开发预览版

本次包为 **v2.1 Inferno 开发预览版**，安装前阅读 [本轮升级与验收说明](deploy/UPDATE-2.1-inferno.md)。

新版 Inferno UI：中文国家/语言搜索多选、中文国家日志、设备/系统/浏览器详情。内置 DB-IP Country Lite 2026-09 离线国家库（署名见 resources/README.md），不把访客 IP 发给第三方查询。设备详情来自可伪造/可能精简的 UA，不保证真实型号；旧日志不补造国家或设备详情。

本轮新增多域名独立管理与 DNS 检查。**自动宝塔建站、反代和证书签发/续期尚未完成，不能只改 DNS 就自动上线。** 请先阅读 [v2 开发预览说明](deploy/UPDATE-2-preview.md)，不要将本包当作已验收的正式升级版。

单管理员自用的 A/B 静态内容与访问规则实验台。支持本地免登录测试，以及独立后台域名 + 访客域名的 HTTPS 部署。公网后台使用账号密码登录，无验证码；不含订阅、续费和团队功能。

**宝塔安装请先阅读 [部署说明](deploy/BAOTA.md)。** 不要直接把本地免登录模式反向代理到公网。安装包已通过本地自动化测试，但尚未在你的 Ubuntu/宝塔服务器部署验收。

## 本地预览（不是公网启动命令）

需要 Python 3.12 或更高版本。在本目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

Linux 本地运行使用 `.venv/bin/python`。后台：http://127.0.0.1:8765 ，测试站点：http://127.0.0.1:8766 。Ctrl+C 停止两个服务。数据默认保存在本目录 `data/`，重启保留；可通过 `--data 路径` 指定独立实验数据。

## 最短使用流程

1. 打开「A/B 内容」，分别上传 `demo/A.html` 和 `demo/B.html`（也附有对应 ZIP），点击「发布此版本」。
2. 在「A/B 内容」页上方点击「放行后展示 A」或「放行后展示 B」，刷新同一个测试站点地址看结果；不用重复上传或发布。
3. 在「访问规则」配置条件并保存，保持概览的规则防护开启：拦截固定到 A，放行到上一步选择的 A/B。用「规则模拟」查看判断过程。概览原有的「全部访问 A/B」是跳过所有规则的全局强制模式，与放行后切换不同。
4. 打开真实测试站点产生记录，然后在「访问日志」查询、导出 CSV。
5. 也可以切换「链接跳转」，给 A/B 添加 HTTP(S) 链接；支持随机、轮询和按历史分配次数均衡。

ZIP 可包含根目录 `index.html` 或一层外包装目录，支持 HTML/CSS/JS/图片/字体等静态资源；文本须为 UTF-8。禁止服务器脚本、配置文件、链接文件、危险路径。限制：压缩包20MiB、500文件、解压总量100MiB、单文件20MiB。单个 HTML 也可直接导入。上传不会立即覆盖发布版本；发布旧版本即回滚。

## 明确定义的规则

- 全局强制 A/B 优先并跳过规则。正常规则模式中，拦截固定到 A，放行（包括白名单）到 `allowed_slot` 指定的 A/B，默认 B。新按钮切回规则模式，但不改变防护开关或过滤条件。
- 规则保护关闭时不检查任何规则，全部访客跟随“放行后展示”的选择。旧配置没有此字段时默认 B，因此升级不会改变原有默认去向。
- 切换针对后续请求，不主动刷新已打开的页面。统计按展示 A/B 分组，不把所有展示 A 的访问都称为拦截；日志原因和模拟过程区分通过与拦截。
- 保护开启：黑名单 > 白名单直接放行 > UA爬虫特征 > IPv4 > 移动设备 > 系统主版本阈值 > 自定义网段 > 国家 > 语言 > 次数。
- 次数按单个 IP 的文档 GET 访问计，前 N 次通过、N+1 次拦截；所有文档访问（含被拦截/强制模式）计数。窗口从首次访问起算，默认24小时；到期或手动重置后重新计算。静态资源、HEAD、预览、模拟不计数。重置不删除日志、不重置链接分配次数。
- 统计保留最近30天且最多10000条文档访问，并非无限历史累计。IP展示掩码；计数标识使用本机密钥HMAC，不保存原始IP到计数表。不记录查询参数、表单内容和认证头。
- 本地仅信任实际连接 IP；公网模式只接受本机 Nginx 并要求它覆盖真实 IP、协议头。国家为空表示不限制；设置允许国家时，无法识别的国家到 A。
- 配置保存有修订号冲突保护；发布和计数使用数据库事务。

## 已知边界

- 对参考站仅参考可见交互；黑白名单冲突、计数边界等未公开细节采用上述本地约定，**不宣称与其私有算法完全相同**。
- 默认使用随包 DB-IP Country Lite 国家库；也可设置 `AB_GEOIP_PATH` 或正式配置 geoip_path 指向自己的合法 Country/City MMDB。指定路径失效时明确告警，不静默改用其他数据源。私网、回环、未覆盖地址和未采集国家的旧日志仍显示未知；模拟器国家字段只是测试输入。IP归属地不代表人或设备的真实位置。
- UA设备/爬虫特征可以伪造，系统版本不代表硬件性能；没有真实爬虫网络身份验证、商业风险库或所谓虚拟卡段自动识别。自定义 CIDR 只按你提供的数据匹配。
- 上传页面在目标端口运行，响应强制沙箱且不授予同源权限。普通脚本与表单可用，但依赖同源存储、Service Worker、模块CORS或跨域API的站点可能不兼容。预览建议使用相对资源路径；绝对 `/资源` 路径会走当前发布路由，而非预览版本。发布后根相对资源正常按规则返回。
- 每个资源请求重新判定，切换瞬间旧页面可能混用新资源；不保证整页跨请求原子快照。
- 多域名控制面已提供；DNS 检查服务可选，自动面板写入保持禁用。不提供 IP 风险供应商和表单采集服务。缺少所选内容时显示维护页503，不偷偷回退另一个槽位。
- 本地模式没有登录；公网必须使用安装脚本生成的 `--config` 配置启动。公网模式包含 scrypt 密码散列、8小时服务端会话、安全 Cookie、CSRF 和登录限速。未设置账号或代理信息不合规时拒绝访问。此版本没有执行真实服务器部署。
- 仅用于自身或明确授权的实验环境，不提供绕过第三方平台审核的保证。
